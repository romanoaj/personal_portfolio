# Portfolio font

The site uses `Cabinet Pixel Serif`, a project-local pixel-grid derivative of
DejaVu Serif Bold. It was made for this portfolio to echo the narrow,
serifed bitmap character of the supplied Pixelta reference while remaining
self-contained and redistributable; see `LICENSE.txt`.

To use a separately licensed Pixelta webfont instead, replace the font source
in the `@font-face` rule at the top of `src/styles/main.css`. Do not redistribute
the personal-use-only Pixelta download on a public website without the required
license.
